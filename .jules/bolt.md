## 2024-04-17 - Asynchronous I/O to Prevent Event Loop Blocking in Express
**Learning:** Node.js's event loop can be severely blocked by synchronous file system operations (like `fs.readdirSync` or `fs.statSync`), especially in API routes serving concurrent requests. Even operations on relatively small directories can cause measurable latency spikes and reduce overall server throughput.
**Action:** When working on Express routes or other I/O bound sections, always prefer the asynchronous Promise-based API (`fs.promises`). Combine independent operations with `Promise.all` (like checking stats for multiple files simultaneously) to maximize concurrency and ensure the main thread remains responsive.
