## 2025-02-12 - Single-Pass Loop Optimization for Analytics Data
**Learning:** In hot endpoints or scripts analyzing historical metrics (like processing 20 past test runs to extract drift metrics and failures), using declarative JS array methods (`filter`, `reduce`, `forEach`) sequentially can lead to unneeded overhead. Intermediate allocations and redundant iterations over the same set.
**Action:** When working on performance-critical or frequently accessed data processing loops, consolidate multiple mapping and filtering passes into a single imperative `for` loop to optimize CPU cache usage and minimize garbage collection pauses.
