## 2025-01-01 - Fix command injection with execFileSync
**Vulnerability:** Found uses of execSync with dynamic arguments.
**Learning:** execSync evaluates dynamic strings via the shell causing injection. execFileSync avoids shell and safely parses args array.
**Prevention:** Prefer execFile/execFileSync over exec/execSync.
## 2024-03-29 - Fixed XSS Vulnerability in ChatBox

**Vulnerability:** Found a Cross-Site Scripting (XSS) vulnerability in `frontend/app/src/components/ChatBox.jsx` where agent messages parsed by `marked` were directly injected into the DOM via `dangerouslySetInnerHTML`.
**Learning:** External content from potentially compromised agents, even after markdown parsing, should never be blindly trusted and rendered directly without an intermediate sanitization step, otherwise a malicious payload could hijack the user's browser.
**Prevention:** Always use a proven HTML sanitizer like `DOMPurify` to clean outputs generated by `marked.parse()` (or any HTML generation routine based on external content) before passing it to `dangerouslySetInnerHTML`.
