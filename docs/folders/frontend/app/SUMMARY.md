## Purpose
The \`frontend/app\` folder contains the core user interface implementation for the dashboard application. It provides the front-end interaction layer for managing tasks, tracking agent states, and displaying system health.

## Key Files
- \`src/\`: Contains all the React components, hooks, and views.
- \`public/\`: Static assets required by the application.
- \`package.json\`: Front-end specific dependencies and build scripts.
- The UI communicates with the backend APIs via fetch requests.
