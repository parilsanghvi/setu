# `tests/test-dashboard-api.js`

## Purpose
This file contains integration tests for the Dashboard API. It mocks the database and verifies API responses and behavior for various endpoints. The dashboard API provides the primary interface for managing tasks, agents, and other core components of the system.

## Exports
None.

## Dependencies
- `express` framework is used for creating the API routes.
- `better-sqlite3` is used as the database driver for persistence.

## Side Effects
None.
