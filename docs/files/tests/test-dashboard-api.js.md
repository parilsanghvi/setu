# `tests/test-dashboard-api.js`

## 1. Overview
This file contains the test suite for verifying the Dashboard API. It tests the functionality of various endpoints exposed by the dashboard server.

## 2. Key Components
*   **Test Suite**: Tests the REST API endpoints.
*   **Endpoints**: Checks endpoints like tasks, agents, and other metrics.

## 3. Usage
Executed during the standard test suite run via `node tests/runner.js` or individually.

## 4. Dependencies
*   `express`: The framework used for the dashboard.
*   Internal test utilities.
