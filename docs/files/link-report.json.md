## Purpose
The \`link-report.json\` file stores the output of the automated documentation link checker. It is used by CI pipelines to detect and fail upon broken markdown links.

## Exports
- JSON file: No explicit code exports.

## Dependencies
- Generated by \`scripts/check-doc-links.js\`.

## Side Effects
- Acts as an artifact. Reading this file does not have side effects, but it influences CI check statuses.
