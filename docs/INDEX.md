## Overview
Setu is an agentic framework designed to help developers build and manage autonomous agents.
It provides a set of tools and libraries to create, deploy, and monitor agents in a distributed environment.
The project is structured around a core library, a backend API, and a frontend dashboard.

This index serves as the entry point for understanding the codebase and its components.
Developers should start by reading the README.md and then explore the documentation linked here.

The project follows a modular architecture with clear separation of concerns.
The backend is built with Node.js and Express, while the frontend uses React and Vite.
Testing is done with Vitest and Playwright.
Linting and formatting are enforced with ESLint and Prettier.
CI/CD pipelines are set up using GitHub Actions.
Docker is used for containerization and deployment.
We use SQLite for local development and PostgreSQL for production.
Redis is used for caching and message queues.
Socket.IO handles real-time communication between the server and clients.
The system is designed to be scalable and resilient.
We follow best practices for security and performance.
