# Pariksha (The Verifier) ✅

Pariksha ensures that changes meet the required standards.

## Capabilities

### 1. `run_tests`
Executes the project's test suite.

```bash
npm test
```

### 2. `check_coverage`
Checks if test coverage meets the 100% standard.
```bash
npm run coverage
```
