## 2024-05-18 - Interactive disabled states and hiding emojis from screen readers
**Learning:** Screen readers often announce emojis in confusing ways (e.g., 'trash can symbol' or 'return hook'). Hiding them with `aria-hidden="true"` and providing clean text or ARIA labels significantly improves the auditory experience. Additionally, using disabled states correctly for interactive async actions requires a combination of `disabled` HTML attributes to prevent multiple submissions, and CSS `:not(:disabled)` paired with opacity changes to communicate state clearly without losing cursor context.
**Action:** Always wrap decorative emojis in `<span aria-hidden="true">` inside buttons, use `disabled` state for any async operation triggers, and consistently apply `:disabled` CSS styling for visual feedback.
